## 기억할 맥락

- 이 프로젝트의 최상위 이름은 주문서비스이며, 상품·재고·알림까지 포함하는 시스템 설계를 뜻합니다.
- Python·AWS·초기 Worker 2대가 출발 조건입니다. MariaDB를 우선 검토하고 Redis·Kafka의 활용을 경험합니다.
- Redis·Kafka를 EKS 안에 둘지 관리형으로 분리할지는 결정하지 않았습니다.
- 앞선 Terraform ZIP은 재설계 전 결과물이며 현재 설계의 확정 코드가 아닙니다.
- 다음 단계에 앞서 전체 인프라나 모든 서비스 코드를 한꺼번에 생성하지 않습니다.
- 현재 문서의 구성 후보는 실제 배포·검증된 결과가 아닙니다.
