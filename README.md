# DevOps

DevOps 환경에서의 **서비스 배포, 인프라 운영, 트러블슈팅** 과정을 정리하는 저장소이다.

클라우드 및 Kubernetes 환경에서 직접 구성하고 검증한 내용을 중심으로, 설정 방법뿐 아니라 구성 목적과 동작 원리, 운영 시 고려해야 할 사항을 함께 기록한다.

## 1. 배포 (Deployment)

애플리케이션과 인프라를 구축하고 배포하는 과정을 정리한다.

- **CI/CD**: Jenkins, GitHub Actions 등을 활용한 빌드 및 배포 자동화
- **IaC**: Terraform, Ansible을 활용한 인프라 구성 및 관리
- **Kubernetes**: Deployment, Service, Ingress, Helm 등을 활용한 서비스 배포
- **GitOps**: Argo CD를 활용한 선언적 배포 및 형상 관리

## 2. 운영 (Operations)

배포된 서비스와 인프라를 안정적으로 관리하기 위한 구성 및 운영 방법을 정리한다.

- **모니터링**: Prometheus, Grafana를 활용한 시스템 및 서비스 모니터링
- **로그 수집 및 분석**: Logstash 등을 활용한 Kubernetes 및 서버 로그 수집
- **고가용성**: 서비스 이중화, 장애 감지 및 Failover 구성
- **보안 운영**: 접근제어, 감사 로그, 취약점 점검 및 보안 설정
- **백업 및 복구**: 데이터 백업, 복원 및 재해 복구 구성

## 3. 트러블슈팅 (Troubleshooting)

인프라 및 서비스 운영 과정에서 발생한 문제와 해결 과정을 기록한다.
