# 상품 주문·재고 서비스

## 사용자가 이용하는 기능

| 기능 | 설명 |
|---|---|
| 상품 목록·상세 조회 | 상품명·설명·가격·판매 상태를 확인합니다. |
| 주문 생성 | 상품과 수량을 선택해 주문을 접수합니다. |
| 주문 결과 조회 | 처리 중·확정·실패 상태를 확인합니다. |
| 주문 목록 조회 | 자신의 주문 이력을 확인합니다. |
| 주문 취소 | 정해진 조건에서 주문을 취소하고 재고를 반환합니다. |
| 결과 알림 | 주문 확정·실패·취소 결과를 확인합니다. |

## 관리자가 이용하는 기능

| 기능 | 설명 |
|---|---|
| 상품 관리 | 상품을 등록·수정하고 판매를 중지합니다. |
| 재고 관리 | 입고 수량을 등록하고 현재 재고를 확인합니다. |
| 주문 확인 | 주문과 처리 결과를 조회합니다. |
| 실패 처리 확인 | 처리가 끝나지 않았거나 실패한 주문을 확인합니다. |

## 기술별 역할

| 기술 | 역할 |
|---|---|
| Python·FastAPI | 사용자·관리자 API와 백그라운드 처리를 구현합니다. |
| MariaDB | 상품·주문·재고의 원본 데이터를 저장하고 트랜잭션을 처리합니다. |
| Redis | 상품 조회 결과를 캐시합니다. 최종 주문 가격과 재고는 원본 데이터를 기준으로 판단합니다. |
| Kafka | 주문 접수 후 재고 처리, 결과 반영, 알림을 이벤트로 연결합니다. |
| Kubernetes | API·Worker의 배포·확장·장애 복구를 담당합니다. |
| Terraform | 서비스 구조가 정해진 뒤 필요한 AWS 인프라를 생성·관리합니다. |
