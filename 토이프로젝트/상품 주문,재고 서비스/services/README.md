# 서비스 디렉터리

[프로젝트 처음으로](../README.md)

각 디렉터리는 업무상 경계와 데이터 소유권을 나타낸다. API와 백그라운드 처리기는 같은 서비스 코드 안에서 필요한 실행 진입점으로 분리한다. 별도 Deployment나 컨테이너가 필요하다는 이유만으로 소스 디렉터리를 나누지 않는다.

| 서비스 | 책임 | 현재 범위 |
|---|---|---|
| [order](order/README.md) | 주문을 접수하고 재고 처리 결과에 따라 주문 상태를 변경한다. | 첫 구현 대상 |
| [inventory](inventory/README.md) | 주문의 재고 확보 요청을 처리하고 결과를 전달한다. | 첫 구현 대상 |

상품·알림 등 다른 서비스는 첫 주문·재고 흐름이 동작한 뒤 필요에 따라 새 디렉터리로 추가한다. 서비스 간 통신 방식, 저장소, 이미지와 배포 구성도 구현에 필요한 범위만 결정한다.
