# 상품 수정

상태: 구현 완료

## 구현 대상

전달된 항목만 수정한다. 판매 중·판매 중지 전환을 포함한다. DB 저장 후 상품 상세 캐시를 삭제한다.

## 제공 API와 동작

`PATCH /api/v1/admin/products/{product_id}`

없는 상품은 404를 반환한다. ID와 생성 시각은 변경할 수 없다. 삭제 API는 제공하지 않는다. 기존 주문 정보는 변경하지 않는다.

## YAML 분담

기능 전용 Deployment와 Service는 만들지 않는다. 상품 API 공통 YAML을 사용한다.

- [Deployment](../k8s/deployment.yaml): 하나의 상품 API 이미지 실행·환경변수 주입·상태 확인 probe
- [Service](../k8s/service.yaml): 상품 API의 내부 접근 주소
- [ConfigMap](../k8s/configmap.yaml): 캐시 TTL 등 일반 설정
- [Secret 예시](../k8s/secret.example.yaml): DB·Redis URL 및 API 키의 예시. 실제 비밀값은 Git에 저장하지 않는다.

세부 설정은 [배포 설정](배포-설정.md)에서 관리한다.
