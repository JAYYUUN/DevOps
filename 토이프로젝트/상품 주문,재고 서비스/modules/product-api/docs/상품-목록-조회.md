# 상품 목록 조회

상태: 설계 초안 / 구현 전

## 구현 대상

판매 중 상품만 페이지 단위로 MariaDB에서 조회한다. 목록 캐시는 적용하지 않는다.

## 제공 API와 동작

`GET /api/v1/products`

page 기본 1, size 기본 20·최대 100. ID 내림차순으로 정렬한다. 목록과 페이지 정보·전체 건수를 반환한다.

## YAML 분담

기능 전용 Deployment와 Service는 만들지 않는다. 상품 API 공통 YAML을 사용한다.

- [Deployment](../k8s/deployment.yaml): 하나의 상품 API 이미지 실행·환경변수 주입·상태 확인 probe
- [Service](../k8s/service.yaml): 상품 API의 내부 접근 주소
- [ConfigMap](../k8s/configmap.yaml): DB·Redis 주소와 캐시 TTL 등 일반 설정
- [Secret 예시](../k8s/secret.example.yaml): 인증정보 항목의 예시. 실제 비밀값은 Git에 저장하지 않는다.

세부 설정은 [배포 설정](배포-설정.md)에서 관리한다.
