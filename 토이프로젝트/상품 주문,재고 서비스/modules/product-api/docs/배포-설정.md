# 배포 설정

상태: 설계 초안 / 구현 전. 현재 파일은 주석 골격이므로 빌드·배포할 수 없다.

## 하나의 컨테이너로 실행

[Dockerfile](../Dockerfile)은 Python·의존성·src 전체를 하나의 이미지에 포함한다. main.py가 라우터를 연결하며 ASGI 서버로 하나의 앱을 실행한다. 파일마다 별도 프로세스를 띄우지 않는다. 실행 명령·이미지 버전은 구현 시 작성한다.

## 파일별 역할

| 파일 | 작성할 내용 |
|---|---|
| [requirements.txt](../requirements.txt) | FastAPI·ASGI 서버·SQLAlchemy·MariaDB 드라이버·Redis 클라이언트의 검증된 버전 |
| [.env.example](../.env.example) | 로컬 환경변수 이름과 입력 예시 |
| [deployment.yaml](../k8s/deployment.yaml) | 이미지·포트·자원·환경변수 주입·live/ready probe |
| [service.yaml](../k8s/service.yaml) | ClusterIP와 Pod 선택 라벨·포트 |
| [configmap.yaml](../k8s/configmap.yaml) | DB/Redis 호스트·포트·DB명·캐시 TTL |
| [secret.example.yaml](../k8s/secret.example.yaml) | DB/Redis 인증정보의 키 이름 예시 |

## 구현 전에 정할 값

네임스페이스, 이미지 저장소·태그, 앱 포트, DB/Redis 주소, 자원 크기, 관리자 인증, 내부 서비스 인증을 확정한다. 실제 Secret은 별도로 주입한다. 내부 API는 경로 이름만으로 보호되지 않는다.

MariaDB와 Redis 자체의 배포는 별도 인프라 구성에서 관리한다. 외부 공개 경로와 NetworkPolicy도 환경이 정해지면 추가한다.

## 구현 후 배포 순서

1. DB·Redis와 인증 수단 준비
2. DB 마이그레이션 실행
3. 이미지 빌드·업로드
4. ConfigMap·Secret·Deployment·Service 적용
5. 상태 확인과 기능 검증
